AI 이미지 생성 + Figma 레이아웃 자동화 가이드

왜 이 문서가 필요한가

07_Figma_MCP_연동_설치가이드.md가 "Claude가 Figma를 직접 조작하는 법"을 다룬다면, 이 문서는 그 앞 단계 — AI가 만든 카피/구조를 실제 이미지와 함께 상세페이지 레이아웃으로 완성하는 법을 다룬다. 두 문서는 세트로 쓴다.

핵심 문제의식: 학생마다 가진 도구가 다르다(무료 클로드만 있는 학생 vs Figma Professional 라이선스가 있는 학생). 그래서 하나의 JSON 스펙을 정해두고, 그걸 "그리는 방법" 2가지 — 07_Figma_MCP_연동_설치가이드.md와 동일한 트랙 A(커스텀 플러그인)/트랙 B(Figma MCP 실연동) — 를 학생 상황에 맞게 고르게 한다. 이 문서는 두 트랙 모두에서 빠져 있던 조각, 즉 이미지 생성을 채운다.

0단계 — 공통 JSON 스펙 (모든 트랙이 공유)

{
  "label": "상세페이지 이름",
  "sections": [
    {
      "type": "SECTION",
      "name": "Section_01_Hook",
      "width": 1200,
      "background": "#111111",
      "children": [
        { "type": "TEXT", "name": "Main_Copy", "content": "...", "fontSize": 36, "fontWeight": 700, "color": "#FFFFFF", "textAlign": "CENTER" },
        { "type": "IMAGE_AREA", "name": "IMAGE_AREA", "width": 760, "height": 600, "background": "#2A2A2A", "prompt": "제품 이미지 생성용 프롬프트" },
        { "type": "BUTTON", "name": "CTA", "text": "지금 구매하기", "background": "#FF6B00", "color": "#FFFFFF", "width": 320, "height": 70, "fontSize": 24, "fontWeight": 700 }
      ]
    }
  ]
}

IMAGE_AREA에 prompt 필드를 넣어두는 것이 이 스펙의 핵심 — 레이아웃이 어떤 방식으로 그려지든(플러그인이든 MCP든) 이 프롬프트를 그대로 이미지 생성 도구에 넘기면 되므로, 트랙이 바뀌어도 스펙을 다시 쓸 필요가 없다.

트랙 A — 커스텀 Figma 플러그인 (완전 무료, 학생 대부분용)

figma-plugin-detail-generator/ 폴더가 실제 동작하는 플러그인이다. Figma 무료(Starter) 계정에서도 100% 동작 — Dev Mode나 유료 플랜이 필요 없다.

파일 역할
manifest.json 플러그인 정의 (networkAccess 허용 포함)
code.js JSON을 파싱해 SECTION/TEXT/BUTTON/IMAGE_AREA를 실제 Figma 노드로 생성
ui.html JSON 붙여넣기 UI
sample-input.json 테스트용 예시 (탁상용 미니 가습기 2섹션)
README.md 설치·사용법 (강사용 배포 절차 포함)

학생 사용 순서 (무료 클로드 웹 버전 기준, MCP·플러그인 연결 불필요):
1. 클로드 채팅창에 "위 스펙 형식으로 [상품명] 상세페이지 JSON 만들어줘" 요청 → JSON 복사
2. 강사가 배포한 플러그인의 붙여넣기 창에 그대로 붙여넣고 "생성" 클릭 → sample-input.json을 넣으면 Hook 섹션 + Trust/CTA 섹션이 Auto Layout으로 즉시 생성되는 것으로 동작 확인 가능
3. IMAGE_AREA는 회색 placeholder로 생성됨 — prompt 값을 아래 "이미지 생성 도구" 표에서 학생이 가진 도구에 그대로 넣어 이미지 생성
4. 생성된 이미지를 다운로드해 placeholder 위에 직접 드래그해서 교체

설치(강사 1회): Figma 데스크톱 앱 → Plugins → Development → "Import plugin from manifest…" → manifest.json 선택 후 학생들에게 배포.

트랙 B — Figma MCP로 클로드가 직접 생성 (플러그인 없이, 07_Figma_MCP_연동_설치가이드.md 환경)

플러그인도 JSON 복붙도 없이, 클로드가 Figma MCP로 파일을 직접 조작해서 완성한다. 학생은 Figma Professional(또는 리모트 MCP 무료 6회 한도) + MCP 연결이 된 Claude가 필요 — 07_Figma_MCP_연동_설치가이드.md 참고.

실제로 만들어본 데모 (이 문서 작성 중 실행, 위 스펙 그대로 사용):
- 새 Figma 파일 생성 → https://www.figma.com/design/8L1jiMLaeaqkiGzF7m67Ea
- 클로드가 use_figma로 Hook 섹션(브랜드/메인카피/서브카피/이미지 영역) + Trust·CTA 섹션(가격/신뢰요소/구매버튼)을 자동 생성
- IMAGE_AREA는 실제 이미지 생성 서버(ComfyUI)가 꺼져 있어 placeholder로 남음 — 이게 중요한 교육 포인트: 이미지 생성 도구가 연결돼 있지 않으면 자동화가 거기서 멈추고 placeholder로 대체된다는 것을 학생에게 직접 보여줄 수 있다. 서버가 켜져 있었다면 같은 흐름에서 이미지까지 자동 삽입됐을 것.
- 이 트랙은 07_Figma_MCP_연동_설치가이드.md의 요금제 제약(Starter 월 6회 등)을 그대로 따른다 — 이미지 생성 유무만 다를 뿐, MCP 설치/제약 안내는 그 문서를 그대로 참조.

학생 실습 프롬프트 예시:

Figma MCP로 새 파일을 만들고, 아래 JSON 스펙 구조로
[상품명] 상세페이지 2개 섹션(Hook, Trust/CTA)을 직접 생성해줘.
완성되면 스크린샷으로 보여줘.

이미지 생성 도구 4종 연동 방법

도구 연동 방식 MCP 자동화 비고
ComfyUI 로컬 서버 실행 중이면 트랙 B에서 generate_image로 완전 자동 생성 가능 (서버 켜져 있을 때만) 서버 꺼져 있으면 위 데모처럼 연결 오류 — 실습 전 반드시 서버 기동 확인
Midjourney Discord에서 수동 생성 → 다운로드 → 트랙 A는 placeholder 위에 드래그 교체, 트랙 B는 클로드에게 이미지 파일을 다시 업로드해 삽입 요청 불가 (MCP 미지원) prompt 필드를 MJ 프롬프트로 그대로 재사용
Gemini (나노바나나) 웹/앱에서 수동 생성 후 동일하게 다운로드→교체 불가 무료 티어 있어 트랙 A 학생에게 적합
GPT 이미지 웹에서 수동 생성 후 동일하게 다운로드→교체 불가 ChatGPT 무료 플랜에도 포함되는 경우 많아 트랙 A 기본값 후보

결론: 완전 자동화(레이아웃+이미지 한 번에)가 되는 조합은 ComfyUI + 트랙 B뿐이다. 나머지 조합은 모두 "이미지 생성 → 다운로드 → 붙여넣기"라는 수동 스텝이 낀다 — 이 사실을 학생에게 먼저 알려주는 것이 [[project_cgd_curriculum_automation]]에서 확인했던 것과 같은 이유로 중요하다: 도구별 무료 범위와 자동화 한계를 먼저 알아야 실습 중 "왜 안 되지?"로 시간을 낭비하지 않는다.

수업 적용 방법

  1. 1차 실습(전체 학생 대상)은 트랙 A로 진행 — 별도 설치 없이 배포된 플러그인만으로 가능.
  2. 트랙 A 플러그인은 강사가 미리 만들어 배포 — 이 폴더의 figma-plugin-detail-generator/를 그대로 공유하거나 Figma Community 비공개 링크로 배포.
  3. Figma Professional 라이선스가 있는 학생 또는 심화반은 트랙 B로 "AI가 디자인 도구를 직접 조작"하는 경험까지 확장 — 07_Figma_MCP_연동_설치가이드.md의 MCP 설치 단계 선행 필요.
  4. 이미지 생성 도구는 학생이 이미 가진 도구를 그대로 쓰게 한다 — 새 도구를 배우는 데 시간을 쓰지 않고, "같은 프롬프트를 다른 도구에 넣었을 때 결과가 어떻게 달라지는가"를 비교하는 실습으로 전환하면 포트폴리오 차별화 포인트가 된다(09_상세페이지_트렌드_2026_취업시장.md의 트렌드 3 "AI 이미지 생성의 표준화"와 직결).

트러블슈팅

증상 원인 해결
플러그인 "생성" 버튼을 눌러도 반응 없음 JSON 문법 오류(따옴표 누락, 쉼표 등) 클로드에게 "위 JSON이 문법적으로 올바른지 검증해줘" 요청 후 재붙여넣기
IMAGE_AREA가 계속 회색 박스로만 남음 이미지 생성 도구 연동이 수동 단계이거나 ComfyUI 서버 미실행 위 도구별 표 참고 — 자동 삽입은 ComfyUI+트랙 B 조합에서만 가능
트랙 B에서 "MCP 서버를 찾을 수 없다" Figma MCP 연결 미완료 07_Figma_MCP_연동_설치가이드.md의 설치 단계 재확인
ComfyUI 연결 오류(ECONNREFUSED) 로컬 ComfyUI 서버가 꺼져 있음 서버 실행 후 재시도 — 실습 직전 서버 상태를 미리 점검하도록 지도
